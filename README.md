# Ising model simulation

Численное моделирование двумерной модели Изинга на квадратной решётке.

## О проекте

Программа реализует модель Изинга для системы спинов на решётке n×n.
Модель используется для изучения фазового перехода ферромагнетик–парамагнетик.
Результаты сравниваются с аналитическим приближением (FLF-теория).

## Метод

- Алгоритм Метрополиса для обновления спинов
- Периодические граничные условия
- Расчёт намагниченности системы при разных температурах
- Сравнение с FLF-теорией (fluctuation-dissipation approach)
- Усреднение по 100 независимым реализациям для каждой температуры

## Файлы

- `ising.cpp` — основная симуляция на C++ (Монте-Карло + FLF-теория)
- `plot_ising.py` — построение графиков по результатам расчёта

# ---FLF--
Проект моделирует двумерную модель Изинга методом Монте-Карло: алгоритм Метрополиса, расчёт намагниченности и энергии. Результаты сравниваются с FLF-теорией. C++ выполняет численный эксперимент, Python строит графики зависимости намагниченности от температуры. Код демонстрирует фазовый переход и приближение теории к эксперименту. Для учебных задач.
